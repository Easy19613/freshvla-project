# FreshVLA

Project page for *FreshVLA: Frequency-Regularized Time Scale Hierarchical Latent Actions for Vision-Language-Action Models*.

[View the project page](https://freshvla.github.io/) · [Read the preprint](https://freshvla.github.io/assets/FreshVLA.pdf)

The page includes four Flexiv manipulation sequences and results on LIBERO, LIBERO-PLUS, CALVIN, and the physical robot. The site is maintained in the [FreshVLA organization repository](https://github.com/FreshVLA/FreshVLA.github.io).
